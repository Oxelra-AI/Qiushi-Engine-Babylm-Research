# Qiushi-Engine-Frontier-Advancement

**Stage I representative model** from the three-stage BabyLM Strict-Small research program: Frontier Advancement → Principle Discovery → Principle-Guided Frontier Advancement.

Produced by the Qiushi Engine autonomous research system.

## Model Summary

- **Architecture**: DeBERTa-v2 with frozen slow adapters (scale 1.75) and private adapters (scale 0.75)
- **Parameters**: 36,458,592 (MLM head) / 36,210,368 (encoder only), including 995,584 private adapter parameters across 48 tensors
- **Vocabulary**: 16,384 tokens (BPE tokenizer)
- **Training data**: BabyLM Strict-Small official corpus (approximately 10M unique words, 64,740 rows) including CHILDES (16,093), Gutenberg (11,621), OpenSubtitles (11,434), Simple Wikipedia (6,619), BNC Spoken (3,599), Switchboard (132), Qwen-derived packed pairs (12,236), and FineWeb-derived compact-view reinvestment text (3,005)
- **Cumulative exposure**: approximately 86M words (within 100M budget). This is *cumulative* presentation count, not unique words; the same legal text presented multiple times is counted each time per official rules.
- **Overall score**: 42.024 (repaired adapter-aware evaluation coordinate)

## Evaluation Coordinate

All nine components evaluated on the repaired adapter-aware coordinate using `FrozenSlowPrivateDebertaV2Model` (36,210,368 parameters) for SuperGLUE fine-tuning (seed 42) and `FrozenSlowPrivateDebertaV2ForMaskedLM` (36,458,592 parameters) for zero-shot tasks.

**AoA** is a genuine 19-checkpoint measurement: the model was evaluated at checkpoints chck_1M through endpoint_86.005295M, producing 152,095 finite surprisal results across 8,005 contexts, with 225 curve-fitted words, raw correlation r = −0.035, p = 0.60. The official evaluator scored this as 0.0 (clipped from the nonsignificant negative raw value). This is a completed measurement, not a missing-checkpoint placeholder.

**Historical note**: The historical platform score 42.121 used a stripped evaluation path (`DebertaV2Model`, 34,219,200 parameters, silently dropping all adapter parameters). The repaired coordinate 42.024 uses the full adapter-aware model. The two values are not interchangeable.

## Data Provenance

Training text derives from BabyLM Strict-Small permitted sources. FineWeb-derived compact-view reinvestment rows are derived text admitted under the same generated-data provision. No external pretrained weights were used.
