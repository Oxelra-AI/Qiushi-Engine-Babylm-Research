# FineWeb Simplification Pairs

This dataset contains the FineWeb sentence-level simplification pairs used in our BabyLM pretraining experiments. The simplified rewrites were generated automatically with Qwen 7B.

The corpus pairs original FineWeb sentences with meaning-preserving simplified rewrites generated by Qwen 7B. It was used to train models such as `go76dof/wwm_curriculum_simplification_40k`, where the model sees original and simplified text during masked language model pretraining.

## Files

- `FineWeb_simplification_pairs.train`: training text with 661,872 lines and 9,999,969 whitespace-counted words.
- `tokenizer/FineWeb_simplification_pairs_40k.model`: 40k SentencePiece BPE tokenizer.
- `tokenizer/FineWeb_simplification_pairs_40k.vocab`: tokenizer vocabulary.

## Data Format

Each pair is stored as:

```text
Original FineWeb sentence.
Simplified rewrite.

Original FineWeb sentence.
Simplified rewrite.
```

Blank lines separate sentence pairs.

Example:

```text
Enlightenment thinkers proposed that human reason coupled with empirical study of the physical world would lead to progress---namely, the advancement of science and the improvement of the human condition.
Enlightenment thinkers believed that using reason and studying the world would lead to scientific progress and better living conditions.
```

## Dataset Details

- Source text: FineWeb-derived English web sentences.
- Rewrite type: sentence-level simplification.
- Rewrite generator: Qwen 7B.
- Size: approximately 10M whitespace-counted words.
- Format: plain text, original sentence followed by simplified sentence.
- Tokenizer: 40k SentencePiece BPE with byte fallback.

## Intended Use

This dataset is intended for small-data language model pretraining experiments, especially BabyLM-style masked language modeling. It can be used to study whether pairing original sentences with simplified rewrites improves sample efficiency.

In our experiments, this dataset was used with both standard token masking and a WWM7 -> Token3 masking curriculum, where the model is first trained with whole-word masking and then with token-level masking.

## Limitations

The simplified rewrites were generated automatically with Qwen 7B and may contain occasional simplification errors, omissions, or changes in nuance. The source text comes from web data, so it may also contain noise inherited from the original corpus.
