## Distinction to preserve

Natural faithful compression changes the examples the model sees. It introduces abstractive compact-side words in ordinary compact contexts, interleaves them with retained content, keeps copied and source-only material present, increases content density, covers source tails, and frees word budget for additional distinct sources. Ordinary WWM then samples this richer distribution without knowing which targets are source-absent.

Explicit target prioritization changes the supervision allocation. It selects a hand-marked high-loss class more often or suppresses another class to fund it. earlier analysis showed that this can improve the intended target readout while displacing the selected BabyLM competencies that matter for the project.

The current ordered-vs-scrambled experiment preserves the natural-text distinction better than earlier analysis: it keeps ordinary WWM and the same compact-view word multiset, changing only whether compact-view words retain their fluent order. It is therefore a legitimate matched test of whether coherent compact context helps the source-absent compact-side signal. It must finish before any new route is started.

## Reading the pending result

For each category `c`, define `D_c = ordered_loss_c - scrambled_loss_c` in the channel probe. Ordered-specific source-absent support means:

- `D_source_absent_content < 0`, so ordered training lowers source-absent compact-side probe loss.
- `D_source_absent_content - D_retained_content < 0` and `D_source_absent_content - D_function_other < 0`, so the movement is not just generic scrambled-text damage.
- The paired source-absent interaction is interpreted together with realized category-specific supervised pieces and the channel exposure reconstruction readiness CUDA selected-count reconstruction. The selected-count split should only be used if the mask-count trace matches both training logs exactly.
- External task movement should be judged primarily through cheap6 without GlobalPIQA, cheap5 without GlobalPIQA/Reading, EWoK+Entity, Supplement, Entity, and COMPS. A GlobalPIQA/Reading-only movement should not promote the route.

## Post-result route if the compact signal survives

The next scientific move should keep the central property of compact data: useful source-absent supervision arises as a consequence of faithful compression, not as an externally prioritized target list.

Two directions preserve that property:

1. Natural-data transfer test: keep ordinary WWM and train a materially different bidirectional masked-LM encoder on matched compact versus noncompact/repetition data, with legal tokenizer/data accounting and selected official-compatible readouts.
2. Natural-density data test: build legal compact-view pools with different naturally arising source-absent content density while matching word budget, source coverage, retained-content mass, source diversity, and ordinary WWM. The manipulation is in faithful compression style and data composition, not in the mask/loss sampler.

Either direction should start with the smallest selected official-compatible slice that can change the research decision, and only after the current matched ordered-vs-scrambled results and whole-word copied-content control are read together.

## Next test after the whole-word-control result

No new GPU training or evaluation is justified before the four managed compact-order tasks deliver. The action is to preserve the route distinction so that a positive source-absent readout does not accidentally recreate the failed source-dependent innovation-masking family.
