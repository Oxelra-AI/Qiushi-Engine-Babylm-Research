## Interpretation

- fineweb relation vs random 1m profile showed relation-explicit FineWeb improved EWoK fast by +3.27 but did not improve Entity fast. The characterization below tests whether the selected examples actually contain repeated-entity transition threads rather than static facts.
- If relation-explicit only increases static relation sentences and not transition threads, the next corpus arm should require repeated entities plus state-changing actions across adjacent sentences.
