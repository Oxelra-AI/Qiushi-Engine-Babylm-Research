## What the dose arm correction and pilot repair establishes

calibrated route options correctly noticed that state-margin readout changed under relation-arm training, but its T-N summary depended on a neutral source-alone anchor. The split arms were trained with source and companion in separate rows, so their elevated N values were plausibly a source-alone/query-format familiarity shift. dose arm correction and pilot reran the scorer on CLEAN, REPEAT, VIEW, REPEAT_SPLIT, and VIEW_SPLIT for both seeds and used the format-matched UPDATED_USE contrast `T(new-source)-U(new-source)`, where both T and U contain source, update, and query/use frame. This keeps T, U, and N visible but makes T-U the primary state-readout quantity.

The result supports a real relation-locality readout, but with an important refinement: both local REPEAT and local VIEW increase update-conditioned state use relative to CLEAN, while split arms are not merely zero; they are consistently below CLEAN on T-U because their U movement is larger than their T movement. Thus calibrated route options should be cited only through this relation arm state margin tu integration/dose arm correction and pilot repair, not as a T-N-only result.

## Scientific interpretation

1. **This is the recurring-content-under-changed-frame target class.** The query asks for the state phrase as it appears in the update while embedding it in a different natural use sentence. On that class the two-seed order is VIEW > REPEAT > CLEAN: VIEW-CLEAN is +0.3656/+0.4036, REPEAT-CLEAN is +0.2083/+0.3318, and VIEW-REPEAT is +0.1573/+0.0719. This matches the earlier Wikipedia overlap face, where content from the source recurs in a changed target frame and VIEW exceeded CLEAN and REPEAT. The state-margin repair is therefore best read as a predicted instance of the relation-typed source-conditioned principle, not as evidence for a new separate second-sentence routine.

2. **Same-window locality survives in the format-matched contrast.** VIEW_SPLIT-CLEAN is -0.0304/-0.1311 and REPEAT_SPLIT-CLEAN is -0.1788/-0.2455 on T-U, while local VIEW minus VIEW_SPLIT is +0.396/+0.535 and local REPEAT minus REPEAT_SPLIT is +0.387/+0.577. Splitting preserves the source/update/use materials but removes same-window relation practice, and the predicted uptake face collapses.

3. **The class boundary is explicit.** This probe scores a phrase recurring from the update inside a new use frame. It does not say that REPEAT helps every recurring token. In compact changed-form probes where the source itself recurs inside heavily rewritten targets, exact-recurrence practice produced negative source-conditioned gain. The report should keep these faces separate: natural-frame phrase recurrence gives VIEW > REPEAT > CLEAN, while exact source recurrence under nonidentical continuation can carry a REPEAT liability.

4. **Split-arm format movement remains part of the evidence.** Raw T is positive for split arms, but raw U is even more positive, so T-U turns negative. Split training appears to move state-phrase/source-format priors or broad update-format response without installing the same true update-to-use relation.

5. **Binding interpretation.** T-U is an uptake face, not a readout for entity-gated selection. The base already has large T-U margins for recent state phrases, and the failed state-use replacement did not improve genuine entity discrimination. A future contrastive-plus-credit experiment should therefore read success from same-source target-updated versus other-entity-updated discrimination on held-out paired packets and from Entity relevant-update strata; T-U and copy gain are side measurements.
