## Main correction to the binary analysis framework for factorial probe substrate

The analysis framework for factorial probe disambiguated construction alternated `initial=opposite` and `initial=same` by sorted state-pair id.  In the held-state bridge rows, this made `initial_pattern` perfectly diagonal with `static_slot`:

- `aligned_state_bridge`: `opposite|st0 = 64`, `same|st1 = 64`
- `inverted_state_bridge`: `opposite|st0 = 64`, `same|st1 = 64`

Thus the binary disambiguated run does not force relation-role inference.  A lower-complexity rule can fit its state rows:

- if `static_slot = 0`, choose the complement of the initial owner;
- if `static_slot = 1`, choose the initial owner.

This rule uses initial owner and static-slot metadata expressed in the text world, not a reusable signed relation coordinate.  Therefore, if the pending analysis framework for factorial probe learned run shows a state gain, it should be treated as preliminary unless evaluation across all four `initial_pattern × static_slot` cells rejects this switch and unless mixed held-seen comparisons show signed aligned/inverted movement.

The CPU script `data/factorial_dataset_audits/factorial_dataset_audit_summary.md` also verified that the analysis framework for factorial probe learned-probe serializer uses only `premise`, `hypothesis` or `text`, plus `label`; it does not serialize row ids or explicit metadata.  The problem is therefore in the text/world construction rather than metadata leakage.  The same script notes that `factorial_probe.py` does not save per-row predictions or checkpoints, so future confirmation runs must preserve per-row outputs.

## Balanced fixed-total family prepared

`scripts/information_budget_substrate.py` generated `data/information_budget_substrate/`.  This is a CPU-only family that keeps total bridge state-pair count fixed at 32 per bridge arm while replacing `k` redundant opposite-initial worlds with `k` independently informative same-initial worlds.  It includes spread and single-relation coverage variants.

The central repaired binary condition is `replace_k16_spread`:

- total supervised rows are unchanged relative to analysis framework for factorial probe bridge arms;
- relation, voice, and static-slot exposure remain balanced;
- every relation×voice×static-slot cell has equal opposite/same counts;
- anti-copy changed-row accuracy becomes 0.5;
- copy-initial changed-row accuracy becomes 0.5;
- event-role changed-row accuracy remains 1.0.

The exact file-backed count for each bridge arm is:

`h0_dax|active|st0|opposite = 8`, `h0_dax|active|st0|same = 8`, and analogously equal counts for every combination of `h0_dax/h2_norp × active/passive × st0/st1`, with the same balance in the inverted arm.  The full table is in `data/factorial_dataset_audits/factorial_dataset_audit_summary.md`.

## What the information family can and cannot support

The balanced k=16 condition is suitable as the next minimal learned confirmation if the analysis framework for factorial probe run has any premise-changing positive result.  It repairs the static-slot diagonal and can test whether the model learns a state-event rule under independently informative worlds.

The low-k files are useful as prepared material, but their learned threshold should not be interpreted without further counterallocation.  The present deterministic selection means k=1,2,4 are concentrated in early relation/voice/static cells, and sorted pair identity may correlate with names or objects.  independent_review verification () recommended treating `replace_k16_spread` as credible for a repaired binary confirmation, while improving low-k allocation before using the sweep as an information-budget law.

Even balanced k=16 can still be solved without a reusable role coordinate.  Remaining alternatives include per relation×voice table lookup, separate state-query and comparison functions, relation-keyed initial-owner switches, or static-owner/equality heuristics.  Therefore the scientific readouts must remain layered:

1. Changed-object accuracy must be high on both initial patterns and both static-slot cells.
2. Unchanged/static facts must remain preserved.
3. Name-permutation and cross-template state readouts should move similarly.
4. Mixed held-seen comparison must show signed aligned versus inverted movement before the result counts as coordinate propagation.
5. If state improves while mixed comparisons stay at chance, the finding is a task-local event/state rule, not reusable relation orientation.

## Prepared per-row runner, not launched

`training/scripts/balanced_budget_probe.py` is a GPU runner prepared for the minimal balanced confirmation.  It defaults to `replace_k00_spread` versus `replace_k16_spread`, arms `aligned_state_bridge`, `inverted_state_bridge`, and `heldheld_only`, and three seeds.  It saves per-row evaluation predictions with logits and reports state cells by `initial_pattern × static_slot × relation × voice`, plus mixed held-seen true-statement accuracy.  It syntax-checks and dry-runs successfully:

- `replace_k00_spread`: common-seen 1024 rows, aligned/inverted 320 supervised rows, heldheld 192 supervised rows; eval suites 512/128/512/512/1024 rows.
- `replace_k16_spread`: same row counts and eval suite sizes.

This runner should not be launched automatically.  First read the completed factorial-probe result.  If analysis framework for factorial probe state rows improve but the static-slot diagonal or missing per-row outputs prevent interpretation, the justified next GPU action is the minimal `k00_spread` versus `k16_spread` run with per-row outputs.  If analysis framework for factorial probe shows no useful training fit or no state movement, do not run a k sweep merely because the files exist.
