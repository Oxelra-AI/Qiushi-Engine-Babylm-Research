# Glossary for Reading the Research

The same term can refer to different objects in different experiments. These definitions apply to this repository's scientific materials. Before interpreting a gain, identify the inputs, targets, comparison models, and evaluation set. Start with the [method documentation](../methods/README.md); original materials are linked from the [notes index](notes/README.md) and [plans index](plans/README.md).

## Text, Relations, and Budgets

| Term | Meaning and limits here | Definitions and original materials |
| --- | --- | --- |
| source | The original text in a pair, providing a content reference for another wording; not program source code. Whether the source actually appears in the model input must be checked against packing and masking conditions. | [Rewrite design](notes/relation_learning/rewrite_generation_design_rationale.md) |
| rewrite / view | Another textual expression of the same source. A "view" is not an image. Generation is intended to preserve meaning, but does not guarantee that every generated text is faithful. | [Compact-view method](../methods/compact_views.md), [semantic-filtering correction](notes/functional_learning/corrected_real_stream_policy.md) |
| compact | A rewrite condition that expresses source content in fewer words. Shorter length does not imply greater informational accuracy. Under a fixed total word budget, saved words can fund additional pairs, so compression must be distinguished from expanded coverage. | [Method](../methods/compact_views.md), [common core and reinvestment](notes/frontier_consolidation/density_core_reinvestment_medium_riskhard.md) |
| relation type | How a source corresponds to its accompanying text, such as verbatim repetition, nonverbatim rewriting, or mismatched correspondence. The relationship required by test targets must also be distinguished. This is not classification of sentences by topic. | [Relation-learning method](../methods/relation_learning.md), [relation and objective boundaries](notes/relation_learning/relation_design_and_objective_boundary_integration.md) |
| same-window / split | The source and accompanying text are jointly available in one prediction window, or are placed in separate training rows. Strict split-window controls preserve each condition's own material collection and budget; early separated conditions with unmatched row counts or packing are not equivalent. | [Content-matched window splitting](notes/relation_learning/twoseed_N_anchored_locality_summary.md), [limits of the earlier separated conditions](notes/relation_learning/relation_design_and_objective_boundary_integration.md) |
| overlap / nonoverlap | In the natural-rewrite probes discussed here, targets are classified by whether their exact token ID appears in the true source. This is not semantic repetition versus semantic novelty, nor necessarily whole-word overlap. | [Target-category check](notes/relation_learning/express_scientific_review_and_wikipedia_correction.md) |
| T / U / N | Three source conditions: T is the true corresponding source, U an unrelated source, and N length-matched ordinary neutral text. N is not empty input. With L denoting loss on the same targets, source advantage is often written L(N) - L(T); larger values mean the true source helps more. Historical T-N loss differences use the opposite direction. | [Original neutral-reference notes](notes/relation_learning/original_threeseed_neutral_anchor.md), [relation-learning method](../methods/relation_learning.md) |
| word / token / exposure | A word is the corpus-accounting unit; a token is a model input unit produced by the tokenizer. One word may contain multiple tokens. Cumulative exposure counts words encountered repeatedly and is not the amount of distinct corpus text. Content actually visible after truncation requires a separate check. | [Budget method](../methods/compact_views.md), [tokenization and visibility](notes/representation_and_objectives/strictsmall_tokenizer_summary.md) |
| tokenization / BPE | Encoding text as a token sequence. Byte-pair encoding (BPE) builds a subword vocabulary by merging basic units. Vocabulary size and tokenizer-training data jointly affect segmentation, embedding capacity, masking targets, and window visibility; compression ratio alone is insufficient. | [Tokenizer correction](notes/representation_and_objectives/corrected_tokenizer_official_vectors_and_route_decision.md) |

## Input, Supervision, and Preservation

| Term | Meaning and limits here | Definitions and original materials |
| --- | --- | --- |
| MLM / WWM | Masked language modeling (MLM) predicts selected original tokens from the remaining input. Whole-word masking (WWM) selects whole-word groups and handles a word's subword pieces together. WWM specifies masking granularity, not necessarily equal loss weight per word. The ordinary recipe selects whole words with approximately 15% probability. | [Masking-granularity comparison](notes/initial_model_studies/wwm_cross_seed_stability_interpretation.md), [training method](../methods/principle_guided_training.md) |
| dense mask | An expanded set of masked content groups in the second view of a paired row, with the source left visible. "Dense" does not mean the entire row or every word is hidden, nor that every masked position contributes to loss. | [Sparse-label correction](notes/relation_learning/sparse_label_interpretation_revision.md), [implementation](../experiments/archive/functional_learning/scripts/densemask_sparselabel_train.py) |
| sparse targets / sparse labels | Content groups selected in the second view by a fixed sampling rule. Only these focused positions contribute to the corresponding acquisition loss. This does not mean predicting only one answer or retaining only sparse parameters. The remaining ordinary text still has ordinary prediction targets. | [Correction to the original notes](notes/relation_learning/sparse_label_interpretation_revision.md) |
| (S,S) / (M,S) / (M,M) | Historical labels specifying the mask set first and supervision set second: sparse masking / sparse supervision, dense masking / sparse supervision, and dense masking / dense supervision. M denotes dense masking here, not a model or a million. Ordinary continued training is not synonymous with (S,S). | [Input and supervision method](../methods/principle_guided_training.md), [condition decomposition](notes/functional_learning/evidence_decomposition_and_missing_controls.md) |
| CE / NLL | Cross-entropy (CE) and negative log-likelihood (NLL). For a true target y, the single-target loss is -ln p(y), with lower values better. Hard-label CE is the specified average of these NLL values; check whether averaging is by token, word group, or target category. The acquisition recipe uses 0.15 * focused CE + 0.85 * ordinary CE, with the two terms averaged separately. The coefficients are not word-count proportions. | [Loss definition](../methods/principle_guided_training.md), [target-type experiment](notes/representation_and_objectives/source_disjoint_target_channel_result.md) |
| KL | Kullback-Leibler divergence, used to constrain predictive distributions. Here the direction is KL(parent \|\| student) = sum_y p_parent(y) * ln[p_parent(y) / p_student(y)], not the reverse. It compares distributions at selected positions under the same input state. Equal coefficients do not imply equal gradient magnitudes. | [Method](../methods/principle_guided_training.md), [direction and randomness correction](notes/functional_learning/preservation_controls_and_corrected_interpretation.md) |
| nats | Units of information or loss when using the natural logarithm ln; 1 nat = 1/ln(2) bits. The sign of CE, KL, or source advantage must be interpreted from its definition. These values are not accuracy percentage points. | [Source loss and units](../methods/relation_learning.md), [original difference direction](notes/relation_learning/original_threeseed_neutral_anchor.md) |
| ordinary state / dense state | The same model's prediction state under ordinary whole-word-masked input or an input with the second view densely masked. These are not ordinary versus dense parameters, or "normal" versus "damaged" models. Target positions must also be fixed or specified in a comparison. | [State and gradient decomposition](notes/functional_learning/evidence_decomposition_and_missing_controls.md) |
| ordinary-state preservation | Constraining the student with the frozen starting model on an ordinarily masked version of the same complete paired row; source evidence remains present. Preservation forward passes disable dropout and restore the acquisition branch's random-number state. The aim is to limit drift in existing predictions, not force every new state to copy the old model. | [Method](../methods/principle_guided_training.md), [correction notes](notes/functional_learning/preservation_controls_and_corrected_interpretation.md) |

## Function and Model Identity

| Term | Meaning and limits here | Definitions and original materials |
| --- | --- | --- |
| functional reach | Which unseen symbols, objects, or queries can still access a learned computation. Here it is operationalized through behavior on familiar and unseen queries, signal formation, and intervention readouts. It is neither accuracy on familiar examples alone nor the span of attention coverage. | [Functional-access method](../methods/functional_access.md), [trajectory analysis](notes/functional_learning/causal_interface_trajectory_analysis.md) |
| activation replacement | During a forward pass, transferring a donor run's full hidden state or selected component at a specified layer and position into a recipient run, then observing whether the answer changes. Parameters are not updated. Replacement shows that the signal can be used; dependence of the original behavior requires erasure or other controls. | [Donor-replacement design](notes/functional_learning/causal_intervention_analysis.md), [erasure and rotation](notes/functional_learning/clean_d_component_ablation.md) |
| selector / reader | A selector chooses a record address based on the query; a reader retrieves the state at that address. They can be trained separately, then composed by passing the selected address to a fixed reader. Successful selection with exact role wording does not imply understanding paraphrases of temporal roles. | [Composition experiment](notes/representation_and_objectives/selector_reader_bridge_synthesis_and_macro_challenge.md) |
| anchor | In graph experiments, supervision fixing the absolute orientation of a few relations; relative comparisons alone need not determine that orientation. In model preservation, the term may instead refer to a frozen reference model. These are distinct experimental meanings. | [Graph-anchor correction](notes/representation_and_objectives/corrected_multiseed_gauge_affine_and_next_raw_binding.md), [residual-learning method](../methods/residual_learning.md) |
| parent | The complete function actually inherited by the current continued-training run or comparison, not a fixed model name. An early experiment froze the model at approximately 82M words and added a branch. In later preservation, the parent is the first-generation model with both branches present and residual scale 0.75, not the older backbone with the added branch disabled. | [Frozen starting-point design](notes/frontier_consolidation/chck82_frozen_private_tail_design.md), [teacher-identity check](notes/functional_learning/evidence_decomposition_and_missing_controls.md) |
| residual / private adapter | A bottleneck transformation whose output is added to the layer output. In historical code, "private" denotes the separately trained added branch, not a privacy technique. Zero-output initialization, recovery of the parent by disabling the branch, and empirical preservation with the branch enabled are different properties. | [Method and implementation entry points](../methods/residual_learning.md), [branch design](notes/frontier_consolidation/adapter_experiment_design.md) |
| seed | The starting value controlling a specified random process. Initialization, data order, continued training, and downstream fine-tuning can each have their own seeds. The same number does not guarantee shared initial tensors across architectures. Two continued-training seeds are not two independent parent-model lineages. | [Shared-initialization correction](notes/frontier_consolidation/commoncopy_architecture_interaction_result.md), [scope of replication](notes/relation_learning/authoritative_ladder_arithmetic.md) |

## Scores and Historical Labels

| Term | Meaning and limits here | Definitions and original materials |
| --- | --- | --- |
| Fast | A screening label, not one standardized complete metric. An early weighted proxy was (3/28) * sum of six metrics + (1/8) * Reading, where the six were BLiMP, Supplement, EWoK, Entity, COMPS, and GlobalPIQA. It used screening subsets and omitted SuperGLUE and AoA. Other programs named "fast" compute an equally weighted seven-metric mean, so inspect the actual formula and sample set. | [Original weighted-proxy notes](notes/compact_experience/masking_curriculum_4m_eval.md), [another fast-scoring implementation](../experiments/archive/frontier_consolidation/scripts/fast_eval_density_arms.py) |
| Cheap7 / equal7 | The arithmetic mean of the six metrics above and Reading, excluding SuperGLUE and AoA. GlobalPIQA's two conditions are averaged first, and Reading is aggregated according to the relevant evaluation definition. The same name does not guarantee the same evaluation-set size; distinguish screening Entity from full Entity in particular. | [Seven-metric implementation](../experiments/archive/frontier_consolidation/scripts/fast_eval_density_arms.py), [screening versus full Entity](notes/frontier_consolidation/density_near_result_interpretation.md) |
| Overall | The arithmetic mean of nine top-level metrics: BLiMP, Supplement, EWoK, Entity, COMPS, SuperGLUE, GlobalPIQA, Reading, and AoA. It is not pooled accuracy over all individual questions. Direct comparison requires a consistent evaluation protocol, complete model identity, and measurements for all nine metrics. | [Results conventions](../results/README.md), [complete paired comparison](notes/relation_learning/authoritative_ladder_arithmetic.md) |
| AoA | An age-of-acquisition metric comparing word-learning trajectories across multiple training checkpoints with human ages of acquisition. The raw correlation must be multiplied by 100 for inclusion in Overall. A measured value set to zero by the significance rule, an unmeasured value, and a zero inserted only by a display convention are different states. | [Unit correction](notes/compact_experience/aoa_unit_correction.md), [evaluation-trajectory boundaries](plans/compact_experience/endpoint_measurement_protocol.md) |
| clean / ordinary / dense | Potentially ambiguous labels. Early CLEAN can denote a data reference; later "clean" can denote ordinary-state preservation with corrected random-number handling. "Ordinary" denotes ordinary WWM continued training. "Dense" must specify whether it refers to masking, labels, or preservation inputs. The name alone cannot establish whether a teacher is used or which data are changed. | [Condition decomposition](notes/functional_learning/evidence_decomposition_and_missing_controls.md), [input and preservation method](../methods/principle_guided_training.md) |

"Not yet run" in a historical note does not become an experimental result merely because a program exists. A correction does not erase the original measurements, but it may withdraw the inference they were used to support. Interpret each value using the linked conditions, units, sample sets, and subsequent corrections.
